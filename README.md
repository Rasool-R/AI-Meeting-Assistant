# AI Meeting Assistant

Bilingual (Persian/English) AI Meeting Assistant designed to process recorded meetings, transcribe speech, identify speakers, generate structured meeting minutes, extract decisions and action items, and support evidence-based question answering across meetings.

## Team Ownership
- **Erfan:** Backend, Data Models, REST APIs, Database, Media Processing (FFmpeg), Speech-to-Text Integration, Security & Infrastructure.
- **Rasool:** LLM Abstractions, Structured Minutes Extraction, Speaker Diarization, RAG & Cross-Language Search, LangGraph Workflows, LangSmith Evaluation.
- **Shared:** Architecture, API Contracts, Security/Privacy, Integration Testing, Release Readiness.
